方案A · 赤痕最小介入

只动「标题 + 饰带 + 底边」三处结构性位置，复刻 logo 的蓝→红走向。
  • 1标题渐变字：linear-gradient(94deg, 亮蓝, 米白 42%, 亮朱, 朱红) 裁切进文字 —— 对应 logo「ASCENDANCE」左蓝右红的鎏金渐变。
  • 2计数徽章转红：描边与数字改亮朱 —— 呼应红轮法阵的印章感，紧随渐变标题右端的红。
  • 3饰带回纹左蓝右红：蓝色回纹上叠一层红色回纹，用 mask-image 只留右段渐显。
  • 4面板底边红色渐隐光线：2px 亮朱光线 + 辉光 —— 对应 logo 下部赤龙尾迹收底。
  • 行内语义色全部不动：稀有度紫 / 橙、优先金、大航海金紫青保留原样。
代码落点：src/App.css → [data-theme="asc"] 增加 --red-* 变量 + 4 处规则，荒野主题不受影响

方案B · 赤痕 + 朱讯行级点缀

在方案A基础上，把「信息闪现」类位置也接入红色语义。
  • 含方案A全部四项改动。
  • 5业务跑马灯转红：点怪成功 / 优先插队提示改用亮朱（现 --hl2 蓝紫）—— 雷光中掺赤信，与「讨伐钤印」的红一脉相承。
  • 6行悬停角标转红：悬停时四角角标改亮朱并加微光，边框仍随稀有度色 —— 模拟游戏内锁定框锁定瞬间的红光。
  • 钤印与撤销垫本来就是红，主题掺红后这两处不再孤立。
代码落点：方案A + .queue-hint 相关两条规则、跑马灯业务态取色改 --red-bright

评审结论（2026-09-26）：采纳方案C（赤雷），去除朱讯两项（⑤ 业务跑马灯转红、⑥ 行悬停角标转红）——跑马灯保持蓝紫，悬停角标保持稀有度色。 已落地 src/App.css（[data-theme="asc"] 变量 + 「凌越主题红纹点缀」规则段）与 src/views/OverlayWindow.tsx（饰带双层结构、红轮水印、第三团红雾），Lite 与完整版共用。
落地说明：三个方案为力度递进关系（A ⊂ B ⊂ C），可任选一档。实施只改 src/App.css 的 [data-theme="asc"] 块与少量规则， 不触碰行内语义色（稀有度 / 大航海 / 优先），荒野主题零影响。凌越主题为悬浮窗外观层，Lite 与完整版共用悬浮窗，两版默认同步生效。
