一、现状与强度差距 观众高光时刻只有一条 12.5px 小字

点怪成功是观众与直播间互动的核心高光时刻（发弹幕 → 上榜 → 看到自己入队），但现状提示只有两处：① 顶栏跑马灯 12.5px 单次滚动文字（10 秒，`--hl2` 橙色小字）；② 新行 0.42s 侧移入场。而队列完成时有 34px 朱印缩砸 + 冲击环 + 十字光的 QUEST CLEAR 大特效 —— 提示强度恰好倒挂：观众加入（高频、高光）无声无息，队列离开（主播操作）反而全场最强。

二、设计语言：金印受理 / 朱印讨伐 与 QUEST CLEAR 成对，不另起炉灶

成对语义：金印受理 ↔ 朱印讨伐

复用完成钤印的全部动画语法（缩砸急停 + 落定回弹 + 冲击环 + 十字光 + 内容压暗），只换印面与色阶：朱红 = 讨伐完成（QUEST CLEAR），金色 = 点单受理（ORDER IN）。观众看一眼就知道「谁加入了、谁打完了」。

同构不同色 · 语义成对 · 风格零漂移

节奏反向：印收行留

完成是「印落 → 行随印走」（印随行离场）；受理是「行入场 → 印落 → 印自己收走、行留下」—— 受理印在行上保留约 0.4s 后淡出上浮，行内容随之从压暗恢复。同一套钤印语言，一收一留两种结局。

印落行留 · 压暗恢复 · 1.55s 全收

强度梯度：受理次强，完成最强

印面 30px（完成的 0.88×）、倾角 -6°、缩砸 0.52s（完成 0.56s）—— 每项收小半档，保证 QUEST CLEAR 仍是全场唯一最强语义。优先插队（打乱排队秩序的大事）用金白高亮印面 + 放射光束 + 双冲击环，在受理档内封顶。

30px < 34px · 优先档金白+rays

ORDER IN

推荐——拉丁衬线大写，与 QUEST CLEAR 印面同工艺成对（CLEAR = 讨伐完，IN = 受理入列）；随包 DM Serif 只需确认 O/D/R/N/I 六字符在子集内。

受注

怪猎任务受理台原词（受注），两字大印最有系列味；但部分观众不识日文汉字，语义传达打折。

点怪受理

中文直白零门槛；四字宋体大印略平，且与跑马灯文案「点怪 xx 成功」重复信息。

优先档印面：插队单印面用 PRIORITY（金白高亮 + 放射光束 + 双冲击环），与普通档同字号 —— 插队是「打乱排队秩序」的大事，值得在受理档内单独封顶；但不再放大字号，避免越过完成印。

六、工程落地清单 评审通过后执行

  1. App.css 新增受理特效段落（不动完成动效段）：.queue-order-fx / .order-stamp / .order-ring / .order-flare / .order-rays 与 .queue-row.ordering 压暗规则，规格按第三节规格表；金色 token 复用 --gold-*（若评审稿未落地则一并新增）。
  2. OverlayWindow.tsx 联动：order-placed 监听里暂存 {user_id, is_priority} 到 pendingOrderRef；applyQueue 的 fresh 检测（187–193 行）命中 user_id 时量 rect（复用 rowRectInPanel）建 fx 层，1550ms 后移除；行加 ordering 类、1.2s 后摘类恢复。
  3. 跑马灯同步增强：order 消息播放期间 marquee span 加金色 + orderMarqueeFlash 辉光（文案逻辑不变，只加样式分支）。
  4. 字体子集确认：印面定 ORDER IN / PRIORITY 后核对随包 DM Serif 子集含 O/R/D/E/I/N/P/Y（QUEST CLEAR 子集已含 E/R，需补 O/D/I/N/P/Y），缺则更新 scripts/fonts/subset_fonts.py 字表重新子集化。
  5. 冲突处理：受理印播放中（1.55s 内）主播点击该行完成时，完成特效照常叠加播放（两层各自定位不冲突）；若评审要求互斥，在完成触发时强制摘除该行受理层。
  6. Lite 形态：点怪队列是 Lite 唯一保留的核心功能，受理印随本体一并生效，无需 ensure_not_lite 守卫、不涉及 IS_LITE 分支。✓ 无额外工作
  7. 验证：纯 CSS/TSX 前端变更 —— 跑 npm run build；人工核对两主题 × 普通/优先两档 × 队首插入/队尾插入，以及受理后立即完成、连续多单快速进入两个冲突场景。
风险备注：① 队列很长时普通点怪新行可能在可视区外（虚拟列表），fx 层 rect 量出来在窗口外则特效自然不可见 —— 跑马灯仍是兜底提示；可选增强：可视区外时改在列表底缘打一枚小号印。② 连续多单快速进入时多个 fx 层并存，各盖各行互不遮挡，冲击环允许交叠（节日感）；若嫌吵可加 300ms 播放间隔队列。③ 印面 1.55s 期间行若被拖拽浮起，fx 层不跟手（完成特效同样不跟手，行为一致）。
