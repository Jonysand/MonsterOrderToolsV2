入口形态

顶部导航新增独立 tab「怪物名单」，位于「点单排队管理」之后。左侧为全量字典图鉴库，右侧为可选名单。

卡片交互

点击卡片 = 入选 / 移出（右上角金勾同步）；悬停左上角铅笔 = 打开条目编辑抽屉（完整字典编辑）。

搜索命中别称

搜索框同时匹配怪物原名与全部别称，可直接用黑话定位（如「大胖虎」→ 嗟怨震天怨虎龙）。

冲突守护

统计卡「别称冲突」点击可直达冲突条目：同一别称被多个怪物占用时，运行时按字典序命中，编辑器在此显式告警。

全选与批量

名单面板「全选」一键纳入全部 175 个怪物；图鉴库「全选结果」把当前筛选（作品 / 状态 / 关键词）命中的怪批量追加，便于按系列圈定本场池。

白名单开关

关闭后弹幕可点全部字典怪物；开启时名单外的点单请求被静默忽略（后续可扩展为跑马灯提示「暂不可点」）。

冲突实时校验

替换关系

原「快速手动点怪」要求输入怪物名/别称并靠模糊匹配，现已整体替换为选怪面板：点图标即可点怪，零输入、零拼错。

名单约束可视化

候选池即「怪物名单」的入选怪；搜索命中的名单外怪物以置灰 + 锁标记呈现，点击只提示拦截原因，不会入队。

确认卡语义

水友昵称 / 身份（总督·提督·舰长·普通） / 难度（跟随字典或强制历战等级） / 优先插队 —— 房管代水友下单时一次填齐，写入与弹幕点单同一条队列。

与弹幕的关系

弹幕「点怪 xxx」仍走别名模糊匹配并在悬浮窗展示队列；面板用于直播中代点与水友诉求的快速响应，两条路径共享名单约束。

Lite 模式

该功能在 ONLY_ORDER_MONSTER=1 下同样可用（属核心点怪能力），不依赖 TTS / 打卡 / AI 模块。
