点怪悬浮窗随包字体 · 许可与出处
================================

本目录下的 woff2 是随应用分发的字体子集，均由下列开源字体子集化而来。
原始字体均采用 SIL Open Font License 1.1（下称 OFL），全文附于本文件末尾。
子集化流程见 scripts/fonts/subset_fonts.py。

1) MH-Serif-SC-MonsterNames.woff2
   来源：思源宋体 Source Han Serif SC（可变字重）
   版权：© 2017-2022 Adobe (http://www.adobe.com/), with Reserved Font Name 'Source'.
   上游：https://github.com/adobe-fonts/source-han-serif
   修改：子集化（仅保留怪物名与固定衬线文案用字）；
         按 OFL 1.1 §3 重命名为 MH Serif SC —— 原保留字名 'Source' 不得沿用于修改版。
   用途：怪物名 / 面板标题 / 完成钤印

2) MH-Sans-SC-Common.woff2
   来源：思源黑体 Source Han Sans SC（可变字重）
   版权：© 2014-2021 Adobe (http://www.adobe.com/), with Reserved Font Name 'Source'.
   上游：https://github.com/adobe-fonts/source-han-sans
   修改：子集化（GB2312 一级常用字 + 应用文案与怪物字典用字）；
         按 OFL 1.1 §3 重命名为 MH Sans SC。
   用途：昵称 / 徽章 / 正文（字表外的冷僻字回落系统字体）

3) DMSerifDisplay-Regular.woff2
   来源：DM Serif Display（原样分发，未做修改）
   版权：Copyright 2014-2017 Adobe Systems Incorporated (http://www.adobe.com/),
         with Reserved Font Name 'Source'. Copyright 2019 Google LLC.
   上游：https://github.com/google/fonts/tree/main/ofl/dmserifdisplay
   用途：顺位数字与计数

被重命名的两个子集仅保留 OFL 要求的版权与许可记录（nameID 0 / 13 / 14），
其余可写名称已改为自有字族名，不再包含保留字名。
